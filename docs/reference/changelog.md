# Changelog

The canonical changelog is [CHANGELOG.md](https://github.com/adamsiwiec1/foss-template/blob/main/CHANGELOG.md)
at the repository root so GitHub Releases and clones see the same file.

Every user-visible change gets a bullet under `## [Unreleased]` in the same
pull request. Before a tag, move that section to `## [x.y.z] - YYYY-MM-DD`.
